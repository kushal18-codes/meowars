# Meowars

A small pixel-art game about cats landing on Mars. Help Pip find three power cells, fix the radio, and plant the crew's flag.

## Play

Open `index.html` in your browser. No installation or build step needed. It works offline.

## Controls

- Drag the joystick to move, or use WASD / arrow keys.
- Press **Interact** or E near a cell, the radio, the flag, or Captain Miso.
- Use **Sound off** to turn sound on.

Built with HTML, CSS, JavaScript, and Canvas. [nipple.js](https://github.com/yoannmoinet/nipplejs) is bundled in the HTML for joystick controls.
